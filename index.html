Habar

Learn Balochi, one short lesson at a time

Habar is a Duolingo-style app for learning Balochi: short lessons, practice, streaks and hearts, with every word shown in Roman and Perso-Arabic script.

Download the Android app (APK)

Install steps: download the file, open it, allow Install unknown apps if Android asks, then tap Install. Requires Android 7.0 or newer.
