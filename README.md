# Habar (هبر) — learn Balochi

A Duolingo-style app for learning Balochi: short lessons, a lesson path, hearts and streaks,
spaced-repetition practice, and Roman + Perso-Arabic script side by side.

**This repository only hosts the downloadable Android app. It does not contain the source code.**

## Download

**[⬇ habar-0.1.0.apk](habar-0.1.0.apk)** — version 0.1.0 (build 1), 52M, Android 7.0 or newer.

On GitHub, open the file page and press **Download raw file** (the ↓ button).

## Install (Android)

1. Download `habar-0.1.0.apk` to your phone.
2. Open it. If Android asks, allow **Install unknown apps** for your browser or Files app.
3. Tap **Install**, then open **Habar**.

> This is an early test build. Vocabulary and features may change, and progress is stored on your
> device (and in your account if you create one).
